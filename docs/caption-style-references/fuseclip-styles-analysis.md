# FuseClip caption styles — frame analysis (Boss's video, 2026-11-23)

Source: fuseclip-edit-styles-recording.mp4 (191s, 1900x1078, screen recording of
FuseClip's Edit step, Styles tab). Boss wants ClipForge captions EVEN MORE
professional than these. Do NOT copy FuseClip's style names (Mumbai, Numaya,
Josh, Aks, Rawani, Headline, Rang) — build ClipForge's own presets that beat them.

## The 7 FuseClip styles (left "Styles" panel, sample text "a quick brown fox")
- Mumbai: Headline font Anton + Script font Kaushan Script; yellow gradient bar
  (5 stops, per-stop Color + Position, Solid/Gradient toggle, Angle slider);
  Level: Word; Secondary #FFFFFF. Preview: Anton caps + script italic mixed.
- Numaya: Font Inter; Layout Center; Primary #FFFFFF; Treatment Emphasize;
  Emphasize #A0D83E (green). Preview: "Hello and WELCOME to FuseClip", green
  glowing WELCOME. Lines field becomes "Auto" when this style is selected.
- Josh: magenta "a" keyword + small white words.
- Aks: big graphic "A" with diagonal stripes background.
- Rawani: teal/green "a" keyword + small white words.
- Headline: stacked bold all-caps white, multi-line centered
  ("A QUICK / BROWN / FOX JUMPS OVER").
- Rang: per-keyword highlight boxes — yellow box "QUICK", magenta box "FOX".

## Global caption settings (right panel)
- Typography: Font size 2.5% (of frame height)
- Layout: Lines 2, Words 4, Max chars Auto, Align lines Center
- Position: Horizontal 50%, Vertical 80%

## Corrected captions (bottom panel)
- Timestamped editable lines (00:00, 00:02, 00:04, 00:07, 00:11...), 23 lines,
  each with a delete button. Word-level text, e.g. "Because this was never...
  This doesn't show to".

## What "more professional than this" means for ClipForge
1. MORE presets than FuseClip's 7 (ClipForge already has 18 — add the missing
   looks: dual-font headline+script, green-glow emphasize, stacked headline,
   per-keyword highlight boxes).
2. Multi-stop gradient editor (up to 5 stops, each color + position changeable,
   Solid/Gradient toggle) — FuseClip has it, ClipForge's Gradient is fixed.
3. Layout controls honored in rendering: lines, words per line, max chars,
   align (left/center/right), horizontal % + vertical % position, font size %.
4. Style preview cards with the sample text "a quick brown fox" in the picker.
5. Timestamped corrected-captions list with delete per line in the Edit step.
