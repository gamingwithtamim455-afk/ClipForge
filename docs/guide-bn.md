# ClipForge — ব্যবহারের গাইড (বাংলা)

## খুলবেন কীভাবে (Windows PC-তে)

1. ইনস্টলারের লিংক থেকে **ClipForge-Setup.exe** ডাউনলোড করুন।
2. ডাবল-ক্লিক → **Install** → **Finish**। ডেস্কটপে শর্টকাট আসবে।
3. ডেস্কটপের শর্টকাট বা Start মেনু থেকে **ClipForge** খুলুন।
4. প্রথমবার খুললে ২ সেকেন্ডের একটা পরিচয় স্ক্রিন আসবে, তারপর Home স্ক্রিন।

> মোবাইলে চলবে না — Windows PC লাগবে।

## ব্যবহার করবেন কীভাবে

1. **New Project** → ভিডিও বেছে নিন।
2. **Viral Clips** স্ক্রিনে ভাষা বেছে নিন (Bengali, English, Arabic, Urdu সহ ১২টা ভাষা)।
3. ক্লিপ কাটার দুই উপায়:
   - **নিজে সময় বসানো (সবচেয়ে ভালো):** Timeline-এ **+** চাপুন, Start/End লিখুন — যেমন `30:00` থেকে `31:00` মানে ঠিক ৬০ সেকেন্ডের ক্লিপ। ভুল সময় লিখলে লাল লেখায় জানাবে, কাটবে না। সর্বোচ্চ ২০টা রেঞ্জ।
   - **Auto:** Clip length আর Clips সংখ্যা বসিয়ে **Start clipping** চাপুন — অ্যাপ নিজে ভালো অংশ খুঁজে নেবে।
4. **Edit** ধাপে ক্লিপগুলো দেখে রাখবেন কি বাদ দেবেন ঠিক করুন।
5. **Render** চাপুন — ক্লিপ তৈরি হবে। প্রতিটি ক্লিপের পাশে একটা `.txt` ফাইলও থাকবে, তাতে TikTok ক্যাপশন আর ৪টা হ্যাশট্যাগ লেখা থাকবে (DeepSeek key থাকলে)।
6. **Render** ধাপে **Copy** বোতামে ক্যাপশন কপি করুন; WhatsApp বোতামে ক্লিপের ফোল্ডার খুলবে।

## API Key বসানো (Settings-এ)

- **Settings → AI Provider:** DeepSeek-এর key বসান। ঠিক থাকলে **Connected** লেখা আসবে, ভুল হলে কারণ লেখা থাকবে (যেমন ভুল key, ব্যালেন্স নেই)।
- **Settings → Transcription:** Deepgram-এর key বসান। না বসালেও চলবে — তখন লোকাল Whisper দিয়ে কাজ হবে (একটু ধীর)।
- Key শুধু আপনার PC-তেই এনক্রিপ্ট করে থাকে — কোথাও পাঠানো হয় না, লগেও লেখা হয় না।

## Key ছাড়া কী কী চলবে (ফ্রি)

ক্লিপ কাটা, মুখ ধরে রাখা (face tracking), ক্যাপশন বসানো, রেন্ডার — সব চলবে। শুধু দুটো জিনিসের জন্য DeepSeek লাগে: **Auto discovery** (অ্যাপ নিজে ক্লিপ খোঁজা) আর প্রতিটি ক্লিপের **TikTok ক্যাপশন + ৪ হ্যাশট্যাগ**।

## জানা সীমাবদ্ধতা

- ইনস্টলার এখনো তৈরি হয়নি — GitHub থেকে build হলে লিংক দেওয়া হবে।
- প্রথমবার লোকাল Whisper ব্যবহার করলে মডেল ডাউনলোড হবে (ইন্টারনেট লাগবে, একবারই, ~৫০০ MB)।
- রেন্ডারে সময় লাগে — ৪০ সেকেন্ডের ক্লিপে কয়েক মিনিট (GPU থাকলে দ্রুত হবে)।
- খুব কাছের শটে (কপাল কাটা থাকলে) অ্যাপ ফ্রেমিং নিয়ে সতর্কতা দেবে — এটা আসল ভিডিওর ব্যাপার, অ্যাপের দোষ না।
- DeepSeek/Deepgram ছাড়া Auto discovery আর hashtag হবে না।
- আপডেট আসে Settings → Updates থেকে — key, সেটিংস, প্রজেক্ট সব থেকে যায়।
